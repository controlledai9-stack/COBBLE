# Cobble Workspace

The saved-file bridge included with the Cobble desktop installer. Cobble installs this extension when you choose Connect IDE; it automatically pairs only the matching local project folder. The bridge reports save events, focus, and connectivity. It does not read unsaved buffers or claim coding-agent integration.

For development, the Cobble: Pair Workspace command accepts pairing JSON from the desktop. Cobble: Disconnect disables automatic connection until you choose to pair again.
